# Product explainer

Use when the point is to show an interface or a workflow.

## Shape

Two to four scenes. Scene one states the promise. Scene two begins assembling
the interface. Scene three, if needed, reveals a result or a detail that proves
the promise.

## Beats

1. Promise: a short headline and a quiet background. No interface yet.
2. Assembly: bring in one component at a time. The first is the hero, later
   ones are evidence. Each arrives on its own beat, 0.35-0.9s apart.
3. Proof: a value changes, a status swaps, or a result appears. This is the
   moment the viewer remembers.
4. Resolve: settle into the smallest state that still proves the message.

## Notes

- Crop the interface so product detail is readable at 1080p. A tiny centred
  browser window is a placeholder, not a product shot.
- Use `data-om-id` on each component so continuity can be measured.
- If scene two continues an actor from scene one, evolve it with measured exit
  states; otherwise use a hard cut.
