# Launch reel

Use when several features must land inside a short film.

## Shape

Four to six scenes, each 3-5 seconds. Every scene has one job. Hard cuts are
the default; use a matched cut only when an actor visibly continues.

## Beats

1. Cold open: identity or provocation.
2. Promise: one sentence stating what changed.
3. Features: one per scene, each with a different framing mode. Vary scale,
   direction and pace so the reel does not read as a list of cards.
4. Proof: a number, a result or a comparison.
5. Close: wordmark, tagline, and a short metadata footer.

## Notes

- Keep the palette and type system identical across every scene.
- Do not use the same entrance three scenes in a row.
- Leave at least one quiet beat; a reel with no breathing room is exhausting.
- The final frame should work as a still thumbnail.
