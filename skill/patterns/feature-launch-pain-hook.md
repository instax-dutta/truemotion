# Pattern: Feature Launch — Pain Hook (video 10)

**Continuity:** `handoff` — `#guide-cursor` + optional `#notification-toast`.

## Beat sheet

| Beat | ~Duration | Content | Blocks |
|------|-----------|---------|--------|
| Pain | 3s | Meeting notification + cursor | `notification-toast-meeting`, `guide-cursor-hand` |
| Hook | 3s | "waiting on *people*" line emphasis | `kinetic-line-emphasis` |
| Promise | 4s | "automatically" mesh word | `mesh-gradient-kinetic-word` |
| Action | 3s | Add button + cursor click | CTA button + `guide-cursor-hand` |
| CTA | 3s | "Try now" text CTA (logo only if provided) | `logo-sting-gradient-mark` / text CTA |

## Cursor handoff

Cursor on toast scene 1 → moves to button scene 4. Match last frame position or cut with cursor already near target.

## Dedup

Same family as `patterns/social-launch-montage.md` but 16:9 and cleaner — prefer this for product launches.
