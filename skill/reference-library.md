# Reference library

Beat sheets for common video types. Read one, then adapt it; do not copy a
pattern wholesale without deciding what makes it right for this brief.

| Pattern | Use when |
| --- | --- |
| [Kinetic title](patterns/kinetic-title.md) | A short identity or chapter card. |
| [Product explainer](patterns/product-explainer.md) | Showing an interface or a workflow. |
| [Data story](patterns/data-story.md) | One number or relationship is the point. |
| [Launch reel](patterns/launch-reel.md) | Several features must land in under 30 seconds. |

Each pattern names the number of scenes, the role of each beat, and where the
hard cuts belong.

## Reusable blocks

- [Block catalogue](blocks/catalog.md) lists small HTML and GSAP shapes.
- [Typing input](blocks/typing-input.md) covers prompt bars and character
  reveal.
- [Hand-drawn shapes](blocks/rough.md) covers the `{{ROUGH}}` token.
- [Local effects](blocks/fx.md) covers the `{{FX}}` token.
