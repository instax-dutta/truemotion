# CLI Reference

- `truemotion init [state.json] [--aspect 16:9|9:16|1:1]` — create state file.
- `truemotion serve --state <file> [--skill <dir>] [--assets <dir>] [--no-preview]` — stdio MCP server.
- `truemotion render --state <file> --out <video.mp4> [--fps 30] [--crf 18] [--audio <file>] [--assets <dir>]` — render.
- `truemotion install-skill <target-dir>` — copy skill dir.
- `truemotion version` — print version.
